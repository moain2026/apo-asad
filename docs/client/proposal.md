# عرض مشروع موقع طيف الضيافة

**إلى: أبو سعد**

**مقدّم العرض: معين العباسي**

**مسودة للمراجعة — لا تُعد اتفاقًا حتى اعتماد البنود كتابةً**

## ١. هدف المشروع

إطلاق موقع عربي لخدمات الضيافة في **الدمام والخبر**، يعرض صور أعمالك والتقديمات المتاحة، ويتيح للعميل أن يرسل لك تفاصيل مناسبته على واتساب أو يتصل بك لطلب عرض سعر. يُثبت اسم «طيف الضيافة» بعد اعتماده والتحقق من توفر النطاق.

## ٢. ماذا يشمل العرض المقترح؟

- **تصميم ومحتوى:** نموذج أولي للمراجعة، شعار وهوية بصرية للموقع، وصفحات للرئيسية والخدمات والتقديمات والأعمال والمدن والتواصل. نرتب صور وفيديوهات شغلك ونحسّن ما نتفق على استخدامه بإذنك.
- **التواصل:** أزرار واتساب واتصال على رقم العمل الذي حددته؛ ربط الموقع بالحسابات المتفق عليها وبريد عمل على النطاق. نثبت عدد الحسابات والمنشورات وما إن كانت الإدارة أو الردود ضمن العرض قبل اعتماده.
- **الظهور المحلي:** تهيئة صفحات الدمام والخبر ليتمكن Google من اكتشافها، وتهيئة الموقع لاستخدامه مع الإعلانات. ملف النشاط على الخرائط يعتمد على الأهلية والتحقق. نتفق هل يشمل العرض إعداد حساب Google Ads أم شرح استخدامه فقط. لا يشمل سعر الموقع ميزانية الإعلان أو إدارة حملات مستمرة، ولا يمكن ضمان ترتيب أو عدد زيارات أو حجوزات.
- **التسليم:** معاينة واعتماد قبل النشر، واختبار واتساب والاتصال، وفيديو شاشة مبسّط، وتسليم الصلاحيات. صيانة وتعديلات مجانية لمدة شهرين وفق حدود وبداية تُعتمدان كتابةً. نفصّل مدة النطاق والاستضافة والبريد ورسوم التجديد قبل الشراء.

## ٣. المراحل والدفعات

| البند | المقترح للتأكيد |
|---|---|
| الإجمالي | 1,900 ريال سعودي |
| الدفعة الأولى | 500 ريال مبلغ ثابت، بعد اعتماد العرض |
| المتبقي | 1,400 ريال؛ نحدد موعد سداده قبل اعتماد العرض |
| البداية | بعد اعتماد العرض واستلام الدفعة الأولى |
| النموذج والتسليم | نثبت تاريخ كل مرحلة قبل البدء؛ تسليم الموقع بعد مراجعة النموذج والمواد واختبار التواصل |

التأجير والجلسات والكراسي والطاولات والفواتير ليست ضمن هذه المرحلة. يمكن مناقشتها لاحقًا في عرض منفصل.

## ٤. المطلوب منك قبل البدء

1. اعتماد الاسم ورقم التواصل المخصص للموقع؛ لا تحتاج لإعادة إرسال الرقم في رد عام.
2. كتابة قائمة الخدمات والمشروبات والمدن التي تخدمها فعلًا.
3. إرسال صور وفيديوهات متنوعة بأصل جودتها عبر القناة الخاصة المتفق عليها، وتحديد ما تسمح باستخدامه وما لا يتوفر له محتوى.
4. تأكيد المبلغ والدفعة وجدول المراحل، واعتماد حسابات الإطلاق وأي تكاليف تجديد.
