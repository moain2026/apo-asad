# رسالة الصباح
صباح الخير أبو سعد، الله يسعد صباحك
لما تصحى كلمني، عندي كم سؤال بسيط نكمّل فيها التحليل والبحث الأولي.

# الأسئلة
الدومين اللي بنشتريه: tayfaldiafa.com

اشرح لنا براحتك، صوتي أو كتابة:
١. وش الخدمات اللي تقدمها بالتفصيل؟ (قهوجيين، صبابين، قهوجيات للنساء، تقديمات، وغيرها)
٢. وش يشمل الطلب عندك؟ (الدلال، الفناجين، التمر، الحلا، البخور، الزي)
٣. أرسل لنا قائمة المشروبات اللي قلت عنها من ١ إلى ١٠.
٤. عندك باقات جاهزة، ولا كل طلب حسب المناسبة؟
٥. وش أكثر المناسبات اللي يجيك فيها شغل؟
٦. تقبل طلبات بنفس اليوم؟ ووش أقل عدد ضيوف تاخذه؟
٧. كم سنة لك في الضيافة؟ ووش يميزك عن غيرك في الشرقية؟
٨. تبي الأسعار تطلع في الموقع، ولا الزبون يسأل على الواتساب؟
٩. عشان خرائط Google نحتاج عنوان في الدمام أو الخبر للتسجيل بس، وما يطلع للناس. وش العنوان؟
١٠. عندك شعار أو فكرة له؟ وعندك تقييمات أو رسائل شكر من زبائن؟

والصور أرسلها على التيليجرام «ملف» مو «صورة».

## داخلي: وش نحتاج لبناء الموقع، ومن وين يجي
| نحتاجه | يغذّي | المصدر |
|---|---|---|
| الخدمات بالتفصيل | صفحات الخدمات + كلمات البحث (قهوجيين، صبابين، قهوجيات) | س١ |
| محتوى الطلب | نصوص الصفحات + الكتالوج في واتساب بزنس | س٢ |
| قائمة المشروبات | قسم الضيافة بالصور | س٣ |
| الباقات | قسم الباقات أو نموذج الطلب | س٤ |
| المناسبات | صفحات المناسبات | س٥ |
| نفس اليوم + أقل عدد | كلمات «قهوجيين اليوم/عاجل» + حقول النموذج | س٦ |
| الخبرة والتميز | نبذة، صفحة من نحن، ثقة Google | س٧ |
| الأسعار | قرار عرضها في الموقع | س٨ |
| عنوان التحقق | ملف خرائط Google (منطقة خدمة، العنوان مخفي) | س٩ |
| الشعار + التقييمات | الهوية + قسم آراء الزبائن | س١٠ |
| الصور | كل الموقع + الفهرسة + الحقوق | التيليجرام |
| المدن | صفحات المدن | **مجاوب**: الشرقية كاملة، الأولوية الدمام والخبر |
| الرقم | أزرار الواتساب والاتصال | **محدد** |
