# 02 — بحث التصميم والنموذج الأولي

المرحلة الثانية بعد `01-preliminary-research`: تحليل واجهات المنافسين بالقياس، ثم نموذج أولي لموقع طيف الضيافة.

| الملف | المحتوى |
|---|---|
| [design-analysis.md](design-analysis.md) | التحليل الكامل: القياسات بالبكسل، المقارنة، قرارات الهوية، التباين، الفحوصات |
| [comparison-mobile-fold.jpg](comparison-mobile-fold.jpg) | الشاشة الأولى على الجوال: القهوة الملكية / كيف / طيف |
| `prototype/index.html` | النموذج الأولي (صفحة واحدة، بدون مكتبات) |
| `prototype/screens/` | لقطات النموذج: جوال وكمبيوتر، الشاشة الأولى والصفحة كاملة |
| `prototype/render.py` | يعيد تصوير النموذج: `python3 render.py` (يحتاج `playwright` و`chromium`) |
| `references/` | لقطات الموقعين المرجعيين، وقياسات المتصفح الخام بصيغة JSON |

**قواعد:**
- النموذج داخلي (`noindex`)، والمجلد خارج أي حزمة نشر (AGENTS.md، البند ٤).
- لقطات `references/` للتحليل فقط. لا تُنسخ منها صور أو نصوص إلى موقع طيف.
- الخطوط تُحمَّل من `docs/client/offer/fonts/` بمسار نسبي. افتح `index.html` من داخل المستودع.
