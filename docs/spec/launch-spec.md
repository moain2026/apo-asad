# مواصفات الإصدار الأول — مسودة داخلية قابلة للاختبار

الهدف: زائر من الشرقية يرى ما تقدمه ضيافة أبو سعد ويطلب عرضًا من رقمه المعتمد. ليس متجرًا ولا حجزًا آليًا أو دفعًا. كل تصور معماري أدناه اقتراح حتى يعتمد معين النطاق. راجع [دفتر القرارات](decisions.md) قبل البدء.

## رحلة الزائر وصفحات مقترحة

| المسار المقترح | ما يعرضه | نتيجة قابلة للتحقق |
|---|---|---|
| `/` | عنوان واضح، نوع الخدمة، الدمام والخبر، صور موثوقة، خدمات رئيسية، خطوات الطلب، دعوة للتواصل | من شاشة الجوال الأولى يمكن رؤية التخصص وفتح واتساب، دون نافذة تحجب المحتوى. |
| `/services` و`/menu` | ضيافة المناسبات، الفئات المؤكدة (قهوة/شاي/مشروبات موسمية وغيرها عند الاعتماد)، صور ووصف لكل فئة | لا يعرض صنف أو فريق أو تجهيز غير معتمد؛ لا تظهر أسعار أو توفر غير مصرح بهما. يمكن دمج الصفحتين في الإصدار الأول باتفاق. |
| `/gallery` | صور أعمال حقيقية مصنفة، وفيديوهات قصيرة إذا وافق العميل | لكل أصل إذن نشر ونص بديل مناسب، والوسائط الثقيلة لا تعطل الصفحة الأولى. |
| `/locations/dammam` و`/locations/khobar` | نطاق خدمة كل مدينة، أمثلة محلية حقيقية وأسئلة مناسبة | كل صفحة مختلفة بفائدة فعلية وتفتح بعنوان ووصف خاصين؛ لا صفحات لمدن لا يخدمها. |
| `/contact` | اتصال، واتساب، بريد عمل وروابط منصات معتمدة | الروابط تفتح الوجهة الصحيحة ولا توجد أزرار معلقة. إخفاء الحسابات التي لم تُسلّم بعد. |

## المتطلبات ومعايير القبول

| ID | المطلوب | الاختبار / الدليل |
|---|---|---|
| R-01 | عربية RTL، واجهة مبسطة ومتجاوبة (DEC-01، 02، 04) | فحص جوال وكمبيوتر، لا تمرير أفقي عند 320px، أزرار واضحة، تنقل بلوحة المفاتيح، تباين مقروء. |
| R-02 | رقم عمل مركزي قابل للتغيير (DEC-03) | تعديل الرقم في مصدر إعداد واحد ينعكس على كل `tel:` وروابط واتساب، وتُرسل رسالة اختبار بموافقة العميل. اضبط الرابط بالصيغة الدولية السليمة؛ لا تنشر مثالًا وهميًا. |
| R-03 | مسار طلب عرض بدون نظام حجوزات (DEC-03، 04) | رابط واتساب يفتح رسالة مسبقة قابلة للتعديل: نوع المناسبة، المدينة، التاريخ، عدد الضيوف. لا تُرسل تلقائيًا من الموقع. أي ترحيب تلقائي يُعدّ من حساب العمل فقط بعد الموافقة. |
| R-04 | هوية وشعار ونموذج أولي ومراجعة محتوى (DEC-01، 07، 10، 11) | رابط معاينة خاص أو ملف نموذج؛ إثبات اعتماد، وقائمة مواد تشمل صاحب الحق وإذن النشر والتصنيف والنص البديل. لا محتوى من العملاء الآخرين. |
| R-05 | صور وفيديو محسنة (DEC-10) | صور بأحجام متجاوبة وتحميل مؤجل لما تحت الطية. يختبر العرض على اتصال أبطأ وموثّق قبل التسليم. لا وعد بزمن قياسي قبل الاختبار. |
| R-06 | SEO محلي تقني (DEC-02، 09، 13) | فحص titles والوصف وcanonical وحالة HTTP وsitemap وrobots والبيانات المنظمة الصادقة؛ إرسال خريطة الموقع عند الإطلاق إذا توفرت الصلاحية. لا ضمان للفهرسة أو الترتيب. |
| R-07 | الحسابات والبريد والخرائط (DEC-07، 08، 13) | بريد نطاق يرسل ويستقبل؛ تسجيل مسؤولية وملكية الحسابات مع العميل؛ تفعيل روابط المنصات المعتمدة فقط. ملف الخرائط مشروط بالأهلية والتحقق، دون عنوان مصطنع. |
| R-08 | إعلانات وقياس (DEC-09) | تحديد منفصل لما يشمله الإعداد والتدريب، وما لا يشمله التشغيل. إن اعتمد القياس، يختبر حدثا `whatsapp_click` و`call_click` بدون بيانات شخصية أو نص الرسالة؛ النقرة ليست حجزًا. لا شراء إعلان من دون موافقة مالية منفصلة. |
| R-09 | التسليم والدعم (DEC-11، 14) | نسخة فيديو شاشة لا تكشف أسرارًا، ودليل ملكية/تجديد، وحدود شهرَي الدعم مكتوبة. فحص مخرجات النشر: لا `docs/` ولا `internal/` ولا نسخ واتساب أو Word أو ملفات بيئة. |

## حدود الإصدار

لا متجر، ولا مدفوعات أو لوحة إدارة أو نظام فواتير، ولا تأجير، ولا ضمان المركز الأول أو زيارات، ولا أتمتة منشورات أو عقد إدارة حملات ما لم يُعتمد صراحة. اقترح بنية موقع محتوى بسيطة بلا قاعدة بيانات قبل ثبوت الحاجة؛ لا تجلب مكتبات أو خدمات قبل اعتماد قرار المنصة. افصل محتوى المدن والخدمات عن إعدادات الهوية والاتصال وأصول النشر. إذا أُضيف نموذج بيانات لاحقًا، أعد تحديد الحقول والخصوصية والتخزين والموافقة.

## بوابات العمل

1. **الاعتماد:** فوّض النطاق، الاسم، رقم العمل، السعر/الدفعة، جدول المراحل ومصدر المحتوى. اطلب من أبو سعد الصور والفيديوهات الأصلية عبر القناة المتفق عليها وقائمة خدمات ومدن مكتوبة. ثبت من يستقبل الرسائل ومتى.
2. **التصميم:** خريطة صفحات، شكل أولي على الجوال، عينة من المحتوى، موافقة مكتوبة. لا تنشر المعاينة إذا احتوت رقمًا أو مواد غير معتمدة.
3. **التنفيذ:** صفحات وإعدادات مركزية وروابط، ثم اختبار R-01 إلى R-09 وتوثيق الاستثناءات. لا تستبدل صور الشغل بأصول توهم أنها من شغل العميل.
4. **التسليم:** موافقة العميل، اختبار الوجهات والبريد وإذن النشر، فحص الخريطة، تسليم الوصول على الخاص والفيديو، وبدء الصيانة حسب الاتفاق. عدم التحقق من خرائط أو إعلانات ليس إذنًا لتجاوز قواعد المنصات.
